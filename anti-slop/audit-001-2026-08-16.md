## Temuan

### HIGH (Hard Gate)

**F-01 [R-02] Em dash (`—`) di teks UI**
Alasan: karakter `—` terlarang; gunakan koma/titik/tanda kurung.
Lokasi: `weekly/page.tsx:445,852,861` | `master/programs/page.tsx:1089` | `monthly/page.tsx:72,924` | `activities/page.tsx:270` (label) | komentar kode `dashboard/page.tsx:533,788`, `weekly/page.tsx:1053` (rendah, ikut dibersihkan)

**F-02 [R-25] Kontras teks di bawah WCAG AA**
Alasan: `text-slate-400` pada putih/slate-50 ~2.9:1 (butuh 4.5:1 untuk teks normal); 12 kasus `text-[10px]` + `slate-400`, 88 penggunaan `text-slate-400`.
Lokasi: `PortalLoginGate.tsx:119` | `master/users/page.tsx` (email/jabatan/unit `text-slate-400`) | teks deskripsi `text-slate-400` di dashboard/monthly/weekly | `weekly/page.tsx:852,861` (`text-slate-300` di slate-900 = ok, tapi konteks)

**F-03 [R-26] Elemen interaktif tanpa perilaku**
Alasan: item marquee punya `cursor-pointer` + hover effects (`hover:-translate-y-1.5 hover:scale-110`) tapi tanpa `onClick`/link.
Lokasi: `MarqueeFooter.tsx:44-53`

**F-04 [R-35] Belum diverifikasi run/build**
Alasan: audit belum menjalankan build (`npm run build`) dan tidak ada bukti pengujian breakpoint mobile (R-03). Verifikasi menyusul saat perbaikan.

### MEDIUM (Purpose-Gate)

**F-05 [R-12, R-01] Neumorphism sistemik tanpa purpose**
Alasan: 128 penggunaan `neu-*` (shadow ganda, inset shadow, gradient 145deg, glow ring) di seluruh UI; teknik default tanpa alasan tertulis.
Lokasi: `globals.css:304-418` (definisi), dipakai di `Sidebar.tsx`, `Header.tsx`, `ModalPortal` child, semua halaman dashboard

**F-06 [R-19] Marquee 60 detik infinite**
Alasan: animasi terus-menerus tanpa UX purpose; `hover:mx-2.5 hover:scale-110` menyebabkan layout shift; `text-emerald-300`/`text-amber-300` dll di atas `slate-950` + 6 warna (lihat F-18).
Lokasi: `MarqueeFooter.tsx:30-56` + `globals.css:420-439`

**F-07 [R-19] Animasi template berlapis**
Alasan: `animate-fade-in-up` dengan `animationDelay` staggered (12x), `animate-page-enter`, `animate-zoom-in`, `animate-dropdown-in` dipakai serentak tanpa purpose per elemen.
Lokasi: `dashboard/page.tsx:562,569,581,601,819,834,855,881,956` | `dashboard/layout.tsx:60` | `globals.css:147-248`

**F-08 [R-13] Glow berlebihan pada chart & elemen aktif**
Alasan: `feDropShadow` glow pada line chart, gradient area chart, `ring-2 ring-emerald-400/40` + shadow glow pada state aktif sidebar.
Lokasi: `dashboard/page.tsx:687-689,747-752` | `Sidebar.tsx:90,114,132` | `globals.css:360-372`

**F-09 [R-07] Background grid pada chart**
Alasan: pola dot-grid `dotGridLight` sebagai latar chart tanpa purpose visual.
Lokasi: `dashboard/page.tsx:684-692`

**F-10 [R-09] Badge dekoratif tanpa fungsi**
Alasan: "SSO Terintegrasi" (capsule + icon), "Portal SSO Live Data", badge `App ID` monospace; kombinasi capsule+border+icon tanpa kebutuhan fungsional nyata.
Lokasi: `PortalLoginGate.tsx:61-63` | `master/users/page.tsx:158-160,169`

**F-11 [R-06] Uppercase label + tracking lebar**
Alasan: 56 teks `uppercase`, label "MENU UTAMA"/"MASTER DATA" `tracking-widest`, judul chart uppercase, header tabel uppercase; tipografi dekoratif ala template AI.
Lokasi: `Sidebar.tsx:77,105` | `dashboard/page.tsx:836,857,884,909` | `master/users/page.tsx:213`

**F-12 [R-11] Radius pill berlebihan**
Alasan: 63 `rounded-full` (badge, tombol, chip, progress) + `rounded-xl/2xl` seragam di semua elemen; tidak ada hierarki radius yang disengaja.
Lokasi: tersebar (badge status, tombol, avatar, progress bar)

### LOW (Quality Locks)

**F-13 [R-31] Tidak ada dokumentasi keputusan desain**
Alasan: tidak ada DESIGN.md; keputusan visual (neumorphism, warna, radius) tanpa alasan tertulis.
Lokasi: root project

**F-14 [R-20] Identitas visual lemah**
Alasan: swap logo => desain tetap terasa sama; neumorphism generik AI; tidak ada motif identitas spesifik.
Lokasi: seluruh shell UI (`Sidebar`, `Header`, halaman dashboard)

**F-15 [R-38] Fallback identitas user hardcoded**
Alasan: "Kurniawan Pralambang" / "Kepala Unit Organisasi Sub Bagian Sistem & IT" sebagai fallback default di kode (nama asli, bukan fabrikasi, tapi identitas diasumsikan di kode).
Lokasi: `Sidebar.tsx:184-185` | `Header.tsx:82,88`

**F-16 [C-4] Teks sangat kecil**
Alasan: 53x `text-[10px]` + 99x `text-[11px]`; beban membaca tinggi di dashboard data-dense.
Lokasi: tersebar (deskripsi, label, badge, tooltip)

**F-17 [R-33/R-31] Dead CSS & selector invalid**
Alasan: `.neu-[badge]` selector invalid (bracket literal), beberapa class neu tidak terpakai; kode sisa.
Lokasi: `globals.css:374-377`

**F-18 [R-29] Palet berlebih di marquee**
Alasan: 6 warna border/teks (emerald, amber, sky, purple, rose, indigo) di satu baris footer + hijau brand = 7 warna aktif.
Lokasi: `MarqueeFooter.tsx:6-13`

**F-19 [R-21] Footer gelap permanen tanpa konteks brand**
Alasan: bar footer `bg-slate-950` tanpa toggle dan tanpa alasan brand; kombinasi light app + dark footer tidak konsisten.
Lokasi: `MarqueeFooter.tsx:34`
